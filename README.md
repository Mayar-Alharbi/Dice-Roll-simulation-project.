# Dice-Roll-simulation-project.
A project that simulates rolling a dice using the programming language C++ on Visual Studio 

This **3D Dice Rolling Simulation** was developed as a graphics programming project to explore low-level rendering pipelines, matrix transformations, and custom physics integration. Built using **C++**, legacy **OpenGL**, and **freeglut**.

The primary challenge was designing a natural and satisfying tumbling animation. The simulation utilizes customized ease-out exponential decay curves coupled with multi-stage dampening bounce functions to accurately simulate gravity, drag, and momentum transfer upon landing.
